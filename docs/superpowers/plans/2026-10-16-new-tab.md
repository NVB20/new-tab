# New Tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Manifest V3 Chrome extension that replaces the new tab page with a speed-dial grid, groups, widgets, preferences, Jump launcher, sidebar and a Speed Dial 2 importer.

**Architecture:** Vanilla ES modules loaded by `newtab.html`, no build step. One store (`js/store.js`) holds all state and notifies subscribers by top-level key; each UI module mounts into a fixed DOM region and re-renders only when its keys change. Pure logic (store normalisation, importer, url/fuzzy helpers) has no DOM or Chrome access and is unit-tested with `node --test`.

**Tech Stack:** HTML, CSS custom properties, JavaScript ES2022 modules, Chrome extension APIs (storage, bookmarks, history, sessions, tabs, favicon, search), Node 22 built-in test runner.

## Global Constraints

- Manifest V3; no inline scripts or inline event handlers (extension CSP).
- No runtime dependencies, no build step. `package.json` exists only for `npm test`.
- Modules imported by tests (`util.js`, `store.js`, `importer.js`) must not touch `window`, `document`, `localStorage` or `chrome` at import time.
- Default theme "Claude dark": `--bg #262624`, `--surface #30302e`, `--surface-2 #1f1e1d`, `--text #faf9f5`, `--muted #c2c0b6`, accent `#d97757`. Light: `#faf9f5`, `#ffffff`, `#f0eee6`, `#141413`, `#5e5d59`.
- Tiles default to white (`#ffffff`) with `#202124` text.
- User-entered text (titles, tasks, notes) is rendered with `textContent` / `dir="auto"`, never `innerHTML`.

### Task 1: Pure helpers and store

**Files:** Create `package.json`, `js/util.js`, `js/store.js`, `test/util.test.js`, `test/store.test.js`

**Interfaces — Produces:**
- `uid(): string`
- `normalizeUrl(input: string): string | null` — trims, adds `https://` when no scheme, returns null if not parseable or empty
- `hostOf(url: string): string` — hostname without `www.`, or the input on failure
- `fuzzyScore(query: string, text: string): number` — 0 = no match; higher = better; case-insensitive subsequence, bonus for contiguous/prefix/word-start matches
- `clamp(n, min, max): number`
- `DEFAULT_PREFS`, `defaultState(): State`
- `deepMerge(base, over)` — returns new object; plain objects merge recursively; when `base[k]` is a plain object and `over[k]` is not, keep base; otherwise `over[k]` wins when defined
- `normalizeState(raw): State` — always returns a valid state (see spec "Data model")
- `createStore(adapter) → { load(), get(), update(fn), replace(state), subscribe(fn, keys?), wallpaper, setWallpaper(dataUrl|"") , flush() }`; adapter: `{ get(key): Promise<any>, set(key, value): Promise<void> }`
- `pickAdapter()` — `chrome.storage.local` when available, else `localStorage` (JSON)
